What This Controls

When analytics is enabled, GeoTrack may collect optional events such as page and detail views, searches, filters, map marker opens, directions starts, outbound booking-link clicks, favorites, collections, and review actions.

Those events can also update inferred interests, which help personalize the Curated for You and recommendation surfaces.

When analytics is disabled, the app stops sending those optional events and the backend ignores authenticated analytics events for your account.
